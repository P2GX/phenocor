class CorrelationResult(correlation_results: DataFrame, coef_matrix: DataFrame, pval_matrix: DataFrame, hpo_labels: dict[str, str] | None = None)

Bases: object

Store and summarize pairwise HPO correlation results.

This class contains the long-format pairwise association results, the symmetric Phi coefficient matrix, the corresponding raw p-value matrix, and optional HPO term labels.

Statistical calculations are performed by HPOCorrelationAnalyzer. This class provides utilities for filtering, exporting, and visualizing the resulting associations.

Parameters:

  • correlation_results (pd.DataFrame) – Long-format table containing pairwise HPO association results.

  • coef_matrix (pd.DataFrame) – Symmetric matrix of Phi coefficients.

  • pval_matrix (pd.DataFrame) – Symmetric matrix of raw Fisher’s exact test p-values.

  • hpo_labels (dict[str, str] | None, optional) – Mapping from HPO term IDs to human-readable labels.

class HPOCorrelationAnalyzer(dataset: PhenotypeDataset)

Bases: object

Analyze pairwise associations between HPO terms.

Pairwise associations are quantified using the Phi coefficient. Statistical significance is assessed using Fisher’s exact test, followed by Benjamini-Hochberg correction for multiple testing.

Only ontology-unrelated HPO term pairs with sufficient pairwise non-missing observations are evaluated.

compute_correlation_matrix(min_individuals: int = 20, n_jobs: int = -1, include_pmids: bool = True) → CorrelationResult

Calculate pairwise associations between HPO terms.

Self-pairs and ancestor-descendant pairs are excluded using the ontology relationship mask. A remaining pair is tested only if at least min_individuals individuals have non-missing values for both HPO terms.

Parameters:

  • min_individuals (int, default=20) – Minimum number of individuals with non-missing values for both HPO terms required to test a pairwise association. This is a pair-specific effective sample size threshold, not a minimum cohort size.

  • n_jobs (int, default=-1) – Number of parallel jobs. -1 uses all available CPUs.

  • include_pmids (bool, default=True) – If True, aggregate unique PubMed IDs from individuals contributing to each tested pair.

Returns:

Pairwise association results together with symmetric Phi coefficient and raw p-value matrices.

Return type:

CorrelationResult

Raises:

  • TypeError – If min_individuals is not an integer.

  • ValueError – If min_individuals is less than 1.
