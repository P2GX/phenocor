phenocor.core.dataset module

class PhenotypeDataset(phenotype_matrix: DataFrame, hpo_labels: dict[str, str]=<factory>, relationship_mask: DataFrame | None = None, phenopackets: list[Phenopacket] = <factory>)

Bases: object

Store an analysis-ready phenotype dataset.

The dataset contains a phenotype status matrix together with HPO term labels, a pairwise ontology relationship mask, and the source Phenopackets.

Phenotype matrix values follow the convention:

1 = observed 0 = excluded NaN = unknown

phenotype_matrix

Phenotype status matrix with individuals as rows and canonical HPO term IDs as columns.

Pairwise HPO relationship mask aligned to phenotype_matrix. Self-pairs and ancestor-descendant pairs are represented by NaN; unrelated pairs are represented by 0.

Type:

phenocor.core.builder module

class PhenotypeDatasetBuilder(phenopackets: list[Phenopacket], *, hpo_file: str | IO[Any] | None = None, hpo_release: str | None = None)

Bases: object

Build an analysis-ready PhenotypeDataset from Phenopackets.

The builder extracts observed and excluded HPO annotations, constructs the phenotype status matrix, propagates annotations through the HPO hierarchy, and constructs the ontology relationship mask.

build() → PhenotypeDataset

Build an analysis-ready phenotype dataset.

Returns:

Dataset containing the propagated phenotype status matrix, HPO term labels, ontology relationship mask, and source Phenopackets.

Return type:

PhenotypeDataset

Raises:

ValueError – If no HPO terms are found in the input Phenopackets or no valid HPO terms remain after ontology processing.
